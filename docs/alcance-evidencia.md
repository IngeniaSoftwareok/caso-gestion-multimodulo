# Alcance de la evidencia

- Estado: beta cerrada según la última confirmación documentada.
- Pantallas y video: datos ficticios; consultas y navegación de demostración.
- El montaje combina tomas identificadas con versiones distintas; no se atribuye a una única release actual.
- Arquitectura y capacidades: documentación y fuentes privadas del proyecto.
- Las pruebas presentes en el proyecto no se suman como una ejecución nueva de este repositorio.
- No se anuncian empresas usuarias, cobros reales, capacidad productiva medida ni funcionamiento completamente offline.
